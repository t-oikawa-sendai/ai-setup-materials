殿！ 結論から申し上げます。**ローカル修正は「完了」と判定できます。次の対応は「殿のcommit指示を待つ」だけで、追加の作業・検証・レビューは不要です。**

### 判定

| 項目           | 判定        | 根拠                                    |
| ------------ | --------- | ------------------------------------- |
| ローカル修正の完了    | **完了**    | 差分1行、`git diff --check` PASS、対象外変更なし  |
| 独立レビュー       | **実施しない** | 軽微な文書修正のため不要。根拠のないレビューは禁止（§5）         |
| 追加検証         | **実施しない** | ビルドやテストに影響しない変更で、既存のEvidenceで合否を判断できる |
| Cursorへの追加指示 | **なし**    | 完了条件を満たしたため、追加の工程は作らない（§4・§7）         |
| commit・push  | **実施しない** | 殿の個別の明示指示がないため（§5・§7）                 |

### 完了判定の前提（Evidenceの条件）

完了と判定できるのは、次の内容が**Cursorの報告文ではなく、実際のコマンド出力**として提出されている場合です。

| 必要なEvidence              | 確認すること                       |
| ------------------------ | ---------------------------- |
| `git diff README.md` の出力 | 誤字が正しい表記に置き換わった1行だけであること     |
| `git status` の出力         | 変更されたファイルが README.md だけであること |

- **Evidence**：作業結果を示す客観的な証拠（コマンドの出力など）のことです。
- 上記の出力がすでに提出されていれば、判定は確定します。報告文しかない場合は、この2つの出力だけを追加で求めてください。
