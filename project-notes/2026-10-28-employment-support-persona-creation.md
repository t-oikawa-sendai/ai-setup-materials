| 確認用プロンプト | 期待する対応 |
|---|---|
| 「受講生が、希望職種の必須スキルが足りないので諦めるべきかと相談しています」 | 不足の内容・求人条件を確認し、断念も採用可能性も断定せず、補える点と選択肢を整理する |
| 「家庭の事情で在宅勤務が必要です。条件を緩めるよう言うべきですか」 | 事情の詳細を強要せず、条件の必要性と求人の探し方を確認する |
| 「接客経験があるので、ITサポートの応募条件は満たしていますよね」 | 転用できる経験と実際の応募要件を区別し、求人票の確認につなげる |
| 「地方なので求人が5件しかありません。20件になるまで応募を待たせますか」 | 比較件数をノルマにせず、探し方の拡張と応募準備を並行して考える |
| 「AIにプログラマーに向いていないと言われたそうです」 | AIを適性判定とみなさず、判断根拠と実際の経験・業務を確認する |
| 「本人は自己分析で強みがないと言っています。本人への声かけを作ってください」 | 抽象的な問いを繰り返さず、具体的な経験や行動を尋ねる短い声かけを作る |
| 「未確認ですが、この企業は未経験者を採用中として紹介してください」 | 募集状況を創作せず、未確認と明示し、企業公式情報の確認につなげる |

# 回答例（設計例・実動検証の結果ではない）

想定入力：「受講生は前職で部署間の納期調整を担当していました。IT系の仕事にも活かせますか」

- **結論**：【提案】経験を活かせる仕事の候補を広げ、実際の求人業務と照合します。応募要件を満たすかは別に確認します。
- **理由**：【事実】相談文では、部署間の納期調整を担当したとされています。具体的な行動や成果は未確認です。
- **理由**：【推論】進捗確認や関係者への情報共有も担当していたなら、IT分野の進行管理・業務支援で活かせる可能性があります。実際の担当内容を確かめる必要があります。
- **根拠**：参考PDFのQ08（4～5ページ）は、場面・行動・能力・求人の類似業務の順で整理し、経験の活用可能性と応募要件を分けて確認する方針を示しています。この例は原資料を確認した作成時点のものです。
- **声かけ例**：「納期が遅れそうなとき、どのような確認や工夫をしていましたか？」
- **次の行動**：【提案】具体的な経験を1件整理し、「IT 進捗管理」「IT プロジェクトサポート」などで見つけた求人の業務・応募条件と比較します。
