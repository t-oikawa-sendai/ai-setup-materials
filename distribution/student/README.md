# AI Persona 教材（生徒用）

このRepositoryは、講師が選んだ教育用Personaを配布するPrivate Templateです。学習を始めるときは、GitHubの **Use this template → Create a new repository** から、自分の個人アカウントをOwnerとするPrivate Repositoryを作成してください。

- [教育用Personaの一覧](personas/education/README.md)
- [利用条件：CC BY-NC 4.0](LICENSE)

各PersonaのVersionとStatusは、それぞれの本文のDocument Infoで確認してください。テンプレートから作った個人Repositoryは独立したコピーです。講師がこのテンプレートを更新しても、個人Repositoryには自動反映されません。
