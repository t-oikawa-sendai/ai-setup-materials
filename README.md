# ai-setup-materials

AI駆動開発を学ぶ受講生向けの、AIエージェント設定・ペルソナ定義の配布リポジトリです。

## 構成

- `personas/education/` — 受講生がそのまま使う教育用定義（Gemini 4Gem構成）
- `personas/reference/` — 実務での多AI運用構成の参考例（Claude / ChatGPT / Cursor / Gemini）
  - 参考例は受講生の環境では動作させないでください。教育用は education 配下のみで完結します。
